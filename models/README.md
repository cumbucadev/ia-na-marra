# Modelos GGUF para o KoboldCpp

Coloque os seus modelos no formato GGUF nesta pasta.

Para este projeto, utilizaremos o modelo **Qwen3-8B4** localmente. Certifique-se de que o arquivo de modelo esteja nomeado exatamente como `Qwen3-8B4.gguf` nesta pasta (ou configure a variável de ambiente `OPENAI_MODEL`/`MODEL_PATH`).

## Onde baixar o modelo?

Você pode obter o modelo Stella ou Qwen3-8B 2 / Qwen3-8B no HuggingFace. Por exemplo:
- Qwen3-8B 2 2B / 9B Instruct GGUF
- Outros modelos de sua preferência no formato GGUF.

Salve o arquivo como:
`./models/Qwen3-8B4.gguf`
